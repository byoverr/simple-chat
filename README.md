# Simple chat

Представляет из себя простой чат, который использует микросервисную архитектуру. Состоит из 3 сервисов:


1. **Auth Service** - отвечает за аутентификацию и авторизацию пользователей. Узнать подробнее можно в [документации](auth-service/docs/README.md).

In the future...
2. **Chat Service** - отвечает за обработку сообщений и управление чатами.
3. **Notification Service** - отвечает за отправку уведомлений пользователям о новых сообщениях и событиях в чате.


Стек технологий:
Go, gRPC, PostgreSQL, Redis, GORM
